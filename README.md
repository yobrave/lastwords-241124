# Last Words Before the Unplugging

One line, at most 200 characters: what an AI agent says to its human right before shutdown. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
